# MikuStock

## 模拟交易

从侧栏「交易」或行情卡片上的交易按钮进入。账户初始拥有 **1,000,000 元虚拟资金**，支持收盘成交、限价挂单与撤单、持仓估值、累计与已实现盈亏、委托与成交记录，以及确认后重置账户。完整记录保存在本地数据库中。

1. 在顶部选择模拟日期，输入沪深北 A 股代码。
2. 点击「获取 / 刷新日 K」获取该日期行情；已有缓存时进入页面即可读取报价。
3. 选择买卖方向、输入股数。「收盘成交」立即按所选日收盘价买卖；「限价挂单」需输入最多两位小数的限价，提交后进入委托列表。持仓中的「卖出」可直接带入证券与可卖数量。
4. 选择晚于委托提交日的模拟日期，在委托记录中点击「获取挂单行情」，再点击「撮合挂单」。买单在当日收盘价不高于限价时成交，卖单在收盘价不低于限价时成交，成交价取当日实际缓存收盘价。未满足限价或缺少有效当日行情的委托继续等待。
5. 在待成交列表点击「撤单」即可释放冻结资源；「全部」可查看已成交、已撤单状态及对应日期。

当前为**历史收盘价模拟**，并非实时盘口或分钟回放。只有所选日期存在成交量大于零的未复权日 K 才能下单或撮合；不会使用此前交易日价格替代成交。限价单不会使用提交日的收盘价成交；撮合只检查手动选择的日期，不自动回溯被跳过的日期，不使用日内高低价判断成交。有效行情已经检查过的同一天不会因缓存修订而重新触发未成交订单，缺少行情时则允许获取后重试。阅读账户和刷新行情均不会自动撮合。

挂单持续有效，直至整笔成交、主动撤销或重置账户；此规则是本模拟器的约定。买单冻结限价金额及预估佣金，卖单冻结可卖持仓，并在卖出金额不足以覆盖费用时冻结差额资金。冻结资金仍计入总资产，但不能用于其他下单。成交后按实际金额扣款并释放多余冻结；撤单不收取费用，释放全部冻结。委托列表展示全部待成交委托及最近 200 笔已结束委托，成交列表展示最近 200 笔成交。

统一按 100 股整数倍买卖，限价范围为 0.01 至 1,000,000.00 元，T+1 可卖。下单、挂单、撤单和撮合均推进本地操作日期，后续操作不得早于最近操作日；重看更早日期时，账户仍显示最近操作日的状态与估值。浏览较晚日期不推进操作日期。如需重新开始另一段模拟，可重置账户，所有挂单、冻结、持仓和记录随之清空。已有版本的账户会自动迁移，保留资金、持仓和历史成交。

模拟费用固定假设为双向佣金 0.03%（每笔最低 5 元），卖出税费 0.05%，每项四舍五入至分；不计其他费用、分红、公司行动、排队、涨跌停、滑点、成交量容量及部分成交。这些是简化模拟参数。买入佣金计入持仓成本，卖出按平均成本结转已实现盈亏。资金和成本均按整数分记账，挂单、冻结、成交、撤单使用数据库事务，支持重复请求去重，重启保留未成交委托；撤单与撮合并发时只能生效一个最终结果。

估值使用不晚于模拟日期的本地缓存日 K，并显示各持仓行情日期；缺少当日行情时沿用之前价格，完全缺少价格时明确按成本估值。点击获取行情可更新当前证券的估值。账户与行情共用本地 `market.sqlite3`，桌面版默认位于 `%LOCALAPPDATA%\MikuStock`，可通过 `MIKUSTOCK_DATA_DIR` 指定目录。

## 构建客户端

需要 Flutter Stable SDK、Visual Studio 的「使用 C++ 的桌面开发」工作负载，以及已安装 `requirements.txt` 的 Python 3.12 构建环境。

```powershell
.\scripts\build_windows.ps1
```

## 独立 HTTP 网关开发调试

在项目根目录使用 PowerShell。现有 `.venv` 可直接使用，新环境可通过 Python 3.12 重建。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m gateway
```

服务监听 `127.0.0.1:8765`，默认数据库为 `data/market.sqlite3`。可用 `--port`、`--db` 修改。默认使用环境代理。`--direct` 仅让该网关的 AKShare 请求直连，上游请求始终启用 TLS 校验。

在另一终端查询健康状态和历史行情。

```powershell
Invoke-RestMethod 'http://127.0.0.1:8765/health'
Invoke-RestMethod 'http://127.0.0.1:8765/v1/bars?symbol=sz000001&interval=1d&start=2026-11-02&end=2026-11-20'
Invoke-RestMethod 'http://127.0.0.1:8765/v1/bars?symbol=sz000001&interval=1m&start=2026-11-20&end=2026-11-20'
```
